# 🤖 HUESC Lite

> A modular AI desktop assistant built with Python and powered by local Large Language Models through Ollama.

HUESC Lite is my long-term personal AI assistant project. It is designed to automate everyday desktop tasks, assist with software development, and eventually evolve into a fully integrated AI ecosystem supporting voice interaction, document analysis, cybersecurity utilities, and home automation.

This project is being built publicly as part of a personal software engineering challenge, with each development milestone documented on LinkedIn and GitHub.

---

## ✨ Current Features

- 💬 Local AI chat using Ollama
- 🚀 Launch desktop applications
- ⚙️ JSON-based application configuration
- 🧩 Modular command routing
- 📁 Project organized into reusable modules
- 💻 Cross-platform application launcher structure

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Tlotlego-B/HUESC-Lite.git
```

Move into the project

```bash
cd HUESC-Lite
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the assistant

```bash
python main.py
```
